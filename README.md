# Banking Business Analyst Portfolio — GitHub Pages

This is a static website. It uses HTML, CSS, and JavaScript and does not require Node.js, a build command, or a package-lock.json.

## Publish it free with GitHub Pages

1. Sign in to GitHub (or create a free account at https://github.com).
2. Click **+** → **New repository**.
3. Name it `portfolio`, choose **Public**, and create the repository.
4. In the repository, choose **Add file** → **Upload files**.
5. Extract this ZIP on your computer, then upload `index.html` and `.nojekyll` from the extracted folder. (You can also upload this README.) Make sure `index.html` is at the repository root, not inside another folder.
6. Click **Commit changes**.
7. Open **Settings** → **Pages**. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch `main` and folder `/(root)`, then click **Save**.
9. Wait a few minutes and refresh the Pages settings. Your website address will look like `https://YOUR-GITHUB-USERNAME.github.io/portfolio/`. Replace the placeholder with your GitHub username.

## Updating the site

Edit `index.html` locally, then upload the updated file and commit the changes. GitHub Pages republishes automatically.

## Before sharing

Open the published site on desktop and mobile. Check that your contact details and all project examples are accurate and that any resume/download links work. This package does not include a separate resume PDF.
